# 📚 Personal Knowledge Base

This repository contains my personal knowledge base built with **Obsidian**.

## Structure

```text
.
├── 00-Inbox
├── 01-Daily Notes
├── 02-Projects
├── 03-Learning
├── 04-Interview Prep
├── 99-Archive
└── README.md
```

## Purpose

* Capture ideas quickly
* Maintain structured learning notes
* Track projects
* Prepare for interviews
* Build a long-term personal knowledge base

## Principles

* One concept per note
* Link related notes using `[[Wiki Links]]`
* Prefer atomic notes over large documents
* Archive instead of deleting
* Keep the vault organized but lightweight

## Tech Stack

* Obsidian
* Git
* GitHub

> This repository is a living knowledge base and will evolve over time.
