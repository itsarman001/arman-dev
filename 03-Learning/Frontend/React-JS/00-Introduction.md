# Introduction

## Naming Convention

There is a convention that each component's name in React should follow **PascalCase**.

| Convention | Example      |
| ---------- | ------------ |
| PascalCase | UserProfile  |
| camelCase  | userProfile  |
| snake_case | user_profile |

See [[React-Fundamentals/01-components-and-jsx|Components and JSX]] for more.
